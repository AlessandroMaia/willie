# v0.1.0 (unreleased)

First slice: the workspace and its development tooling, the architecture
documents, and F0 — the Willie distribution, its daemon and the Dashboard
health view, in a per-user Windows installer.

## Added

- Cargo workspace with the core, protocol, harness, plugin and platform
  crates, each compiling with one test.
- Development tooling: pinned toolchain, `just` recipes, `cargo xtask`
  (`doctor-tools`, `check-refs`, `build-linux`, `distro`), pre-commit
  hook, strict formatting and lints.
- Tauri 2 + React application shell showing the running version.
- Architecture, CLI contract, testing guide and the first decision records.
- The Willie distribution image (Debian slim + Willie binaries), built with
  `just distro-build` and bundled in the installer.
- `willied` answers `daemon.hello`, `daemon.health`, `daemon.doctor` and
  `daemon.shutdown` over stdio; `willie doctor` inside the distribution.
- `willied` serves the `project.*`, `job.*` and `state.*` methods over
  stdio: it owns the projects, runs their git work as background jobs and
  streams `state.event` with a monotonic `seq` from a single writer, so a
  client keeps its view current from one `state.snapshot` plus the events.
- Projects: register a Windows checkout, work on an ext4 clone inside
  the distribution, and sync both ways from the Projects screen;
  `just test-linux` runs the daemon's tests inside the distribution.
- Dashboard: WSL / distribution / daemon / doctor health, install and
  daemon actions, doctor report with remediations.
- Windows installer (NSIS, per-user).
- Sessions (Linux core): the daemon creates, stops, lists and re-adopts
  Claude Code sessions; a detached supervisor owns each PTY and outlives
  the daemon; `willie attach` connects a terminal; the harness is
  detected and installable from the daemon.
- Open a Claude Code session for a project with one click, straight into
  a Windows Terminal tab.
- Open a live session inside the Willie window itself (an embedded
  terminal), as an alternative to the Windows Terminal tab.
- Sessions screen: attach or stop a running session, and see the most
  recently finished ones.
- Install the Claude Code harness from the Dashboard, with progress.
